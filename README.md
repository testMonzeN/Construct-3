## Как скачать и запустить

1. Открой репозиторий: https://github.com/testMonzeN/Construct-3  
2. Нажми зелёную кнопку **Code** → **Download ZIP**  
   *(или клонируй: `git clone https://github.com/testMonzeN/Construct-3.git`)*  
3. Распакуй архив (если ZIP).  
4. Открой **`EchoKnight.c3p`** в [Construct 3](https://www.construct.net/).  
5. Preview (F5) — играть.

Для команды: доска задач и база знаний — в [YouGile EchoKnight-OPD](https://ru.yougile.com/team/5daa76148f04/EchoKnight-OPD).
