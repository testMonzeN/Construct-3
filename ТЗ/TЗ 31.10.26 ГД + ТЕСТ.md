1. Шаги (меню → …)
2. Ожидание
3. Факт

**Не предлагать в код без проверки:** поведения Construct **LOS** и **Pathfinding** — ломают проект.

## Для тестера (Владислав)

### Цель

Полный прогон текущего билда, баг-лист без «игра не открывается» / «миссия не завершается» / «хаб сломан».

### Обязательно сделать

1. **Смоук (каждый день работы над билдом)** — 5–8 мин из [`05_Для_тестера.md`](./05_Для_тестера.md#smoke).
2. **Полный чеклист** — все 14 пунктов в конце того же файла.
3. **По одной миссии каждого типа 0…6** хотя бы раз (на любой планете).
4. **Один босс планеты** до фазы 2 и убийства.
5. **Кузница + моды:** стихия, ковка пушки в слот 2, мод до капа веса; слот 1 = эхо не затирается.
6. **Стелс:** Shift + тихий удар; враг за стеной не агрится.
7. **Пауза P** — нет стрельбы/рывка; **R** после смерти → меню.

### Сдать

- Карточка YouGile «Тест прогон» со статусом и списком багов (или вложенные карточки).  
- Отметить в комментарии: какие пункты чеклиста ✅ / какие ❌.  
- Блокеры — сразу пинг разработке.

### Критерий «тест ок»

Нет блокеров на: старт → хаб → узел → победа → хаб → кузня/моды → ещё узел. Босс хотя бы одной планеты проходим.

## Для геймдизайнеров (Timer, Дима)

### Цель

По ощущениям забега и багам теста подготовить **ECH-9** (правка баланса/текстов), без смены архитектуры игры.

### Обязательно сделать

1. **Сыграть самим** минимум: реликвия → 2–3 узла → кузница → смена оружия/модов.
2. По результатам теста (и своим) заполнить таблицу **ECH-9** — только то, что реально хотите поменять:

| Лист | Что писать |
|------|------------|
| `правки` | Было → стало → зачем (коротко) |
| `миссии` | Если меняете волны / бур / шпионаж / спасение |
| `враги` | Если слишком мясо / вата на слое N |
| `босс` | Фаза 2, HP, награда |
| `кузница` | Цены золота / ядер, лимиты |
| `реликвии` | КД / сила |
| `тексты` | Имена узлов/планет, подсказки, победа/поражение (русский) |
| `хотим позже` | Идеи **не** в этот спринт |

3. **Темп забега:** целевое ощущение ~**6–12 мин** до босса 1-й планеты для знакомого игрока (не спидран). Если дольше/короче — правка в таблице.
4. **Не ломать:** типы миссий 0…6, F/V/E/M, размеры локаций, слот 1 = эхо.

### Сдать

- Excel / Google Sheet **ECH-9** + ссылка в карточке YouGile «ECH-9 баланс».  
- Короткий комментарий (5–10 строк): что болит сильнее всего (сложность / скука / непонятные тексты).  
- Список «не трогаем в ECH-9» — чтобы дев не гадал.

### Критерий «GD ок»

Таблица с конкретными числами/текстами; дев может перенести без созвона «а что вы имели в виду».

## Совместно (синхрон)

1. Тест гоняет чеклист → заводит баги.
2. GD по багам «это баланс / это текст / это баг кода» — тег в карточке.
3. Баги кода → разработка. Баланс/тексты → ECH-9 → разработка.
4. После нового `.c3p` на GitHub — тест делает **регресс** (смоук + бывшие блокеры).
