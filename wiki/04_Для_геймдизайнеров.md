## Что уже в билде (не сетка 3×3)

- 6 планет, у каждой своя цепочка узлов; между узлами — **корабль-хаб**  
- Локация узла **3840×2160**, типы миссий 0…6 (истребление / волны / оборона / элита / босс / шпионаж / спасение)  
- Стелс, тихий удар, зрение сквозь стены режется  
- Кузница: стихии + крафт пушек; автомат модов (вес / ёмкость 12)  
- Лимит **50 событий Construct снят** — можно предлагать механики сложнее, но разумный объём  

## Что сдать

Один Excel / Google Таблица, листы:

1. `миссии` — типы 0…6, волныры волн / бур / стелс  
2. `враги` — архетипы 0…7 + скейл от `enemyLevel`  
3. `босс` ← **отдельный лист (важно)** — фазы голема  
4. `кузница` — ядра, пушки, моды  
5. `реликвии` — heal / shield / nova  
6. `тексты` — лор, имена узлов/планет, победа/поражение  
7. `хотим позже` — опционально  

## Босс (обязательно в таблице)

- HP, урон, скорость, золото  
- Фазы (сейчас порог ~50% MaxHP)  
- Адды / призывы  
- Темп: забег ~6–12 мин, босс не ваншот и не стенка  

## Не ломать без согласования с кодом

- Поток хаб ↔ узлы ↔ планеты (F / V)  
- Управление WASD / ЛКМ / Пробел / Q / Shift / T / E / M / G  
- Размеры мира / хаба и типы `MissionType`  

Без таблицы баланс в код **не** правим «на глаз».
