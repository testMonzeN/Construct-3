# Об игре — Эхо-Рыцарь

**Эхо-Рыцарь** — космический рыцарь с эхо-клинком и пушками стихий. Забег: корабль → планета → узлы-миссии → босс мира → следующая планета.

## В двух словах

- Открыл `EchoKnight.c3p` в Construct 3 → Preview.
- Меню → выбрал реликвию → попал на **корабль-хаб**.
- **F** — карта узлов, клик по доступному → большая локация.
- Выполнил цель → снова хаб → качайся в кузнице (**E**) / модах (**M**).
- Последний узел планеты — **голем**. **V** — звёздная карта планет.

## Сеттинг

Вселенная Эха: шесть миров от леса до бездны. Корабль — мобильная кузница между высадками. Оружие ковуется из **ядер стихий** (огонь / лёд / молния), найденных в бою. Враг не видит сквозь стены; стелс и тихий удар — отдельный путь рядом с лобовым штурмом.

## Петля забега

```
Меню → реликвия
    → Хаб (кузня / моды / карты)
        → Узел (миссия на 3840×2160)
            → цель выполнена → Хаб (+хил)
        → …узлы…
        → Босс планеты → следующая планета (V)
    → все 6 миров / смерть → меню (R)
```

## Столпы геймплея

| Столп | Что это |
|-------|---------|
| Миссии | 7 типов: истребление, волныны, оборона бура, элита, босс, шпионаж, спасение |
| Хаб | Кузница, автомат модов, карта узлов (F), карта планет (V) |
| Билд | Слот 1 всегда эхо-клинок; слот 2 — кованая пушка; моды на пушке (4 слота, вес ≤12) |
| Стелс | Shift уже обзор врагов; T — тихий удар по незаагренному |
| Пространство | Большие карты со стенами, миникарта, рывок не сквозь стены |
