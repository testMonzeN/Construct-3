# Старые баги (архив)

Список закрытых багов и **почему так выходило**. Без описания правок.

---

## Ранняя разработка

- **Проект не открывался / «не действительный»**  
  Почему: дубли ID событий, кривая упаковка `.c3p`, иногда неверные действия Construct.

- **LOS / Pathfinding / ручной скролл ломали `.c3p`**  
  Почему: эти готовые поведения/действия в нашей сборке давали битый файл.

- **Ошибки выражений (скобки, Self у System)**  
  Почему: лишняя скобка в тексте цели; `Self` в системной формуле (Self только у объекта).

- **Пули летели сквозь стены**  
  Почему: не было столкновения пули со стеной / пуля не делала пошаговую проверку.

- **Враги ходили / видели сквозь стены**  
  Почему: не было выталкивания из стен; обзор считался «напрямую», без проверки стены на луче.

- **На миникарте серый лишний блок**  
  Почему: на карту рисовали стены хаба как отдельный слой.

- **Гигантские формулы в одном тексте HUD / цели / узлов**  
  Почему: всё состояние игры запихивали в одно длинное выражение в одном Text.

## Прогоны до 04.11

- **Оружие с пола подбиралось в миссии и с любого расстояния**  
  Почему: не было ограничений «только хаб» и «подойти близко».

- **Арена элиты без прохода (глухой короб)**  
  Почему: раскладка стен без дверного проёма.

- **В меню описание реликвии смешивалось с гайдом управления**  
  Почему: один и тот же текст использовался и для описания, и для подсказки.

- **Тихий удар не работал**  
  Почему: враг замечал раньше, чем игрок входил в радиус удара; цель выбиралась неверно (уже в тревоге / не ближайший «спящий»).

- **Враги стояли АФК (зачистка / волны / спасение)**  
  Почему: пока их не увидели — не было патруля, только «стой и жди».

- **После предпоследнего узла скипался босс планеты**  
  Почему: сначала увеличивали номер узла, потом проверяли «это был последний» — условие уже смотрело на новый номер.

- **Кузня / врата с любого расстояния, моды только вблизи**  
  Почему: у разных объектов хаба были разные (или нулевые) проверки дистанции.

- **Ковка затирала эхо-клинок в слоте 1**  
  Почему: крафт писал новую пушку в основной слот, а не во второй.

- **На обороне слишком узкие щели**  
  Почему: проёмы в кольце стен были уже спрайта героя.

- **Рывок проходил сквозь стены**  
  Почему: телепорт/сдвиг сразу в точку, без проверки стены по пути.

- **На паузе можно было стрелять / делать рывок / крутиться**  
  Почему: пауза ставила time scale 0, но ввод боя не проверял «на паузе ли мы».

- **Один клик в кузне / модах = двойная покупка**  
  Почему: клик ловили и кнопка, и подпись поверх неё → два срабатывания.

- **Спрайт и имя оружия на полу не совпадали**  
  Почему: картинка/подпись брались из устаревших данных, а не из актуального типа на полу.

## 04.11.2026 (тест)

- **Тост при подборе с пола путал «взял» и «бросил»**  
  Почему: после обмена имена в HUD ещё не обновили, тост читал старое имя.

- **На паузе открывались кузня / моды / карты / пол**  
  Почему: запрет паузы стоял на бое, но не на хаб-меню и пол.

- **Волны и оборона кончались на предпоследней волне**  
  Почему: при спавне последней волны счётчик уже «макс», а врагов ещё 0 → срабатывала победа раньше боя.

- **После 5-й планеты сразу экран победы забега**  
  Почему: смена 5→6 и проверка «финальный мир?» шли в одном вызове: после +1 мир уже считался шестым.

- **Из открытого меню хаба можно было убежать и жать UI**  
  Почему: дистанцию проверяли только при открытии; герой продолжал ходить.

- **Тихий удар снова не работал**  
  Почему: радиус удара (50) был меньше стелс-обзора врага (85) — замечали раньше удара.

- **На шпионаже подкрепление застревало в стенах**  
  Почему: спавн с краёв карты, путь к терминалу через лабиринт.

- **На обороне спавн всегда в одних точках**  
  Почему: фиксированные точки появления без рандома.
