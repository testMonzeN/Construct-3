# Кузница знаний — EchoKnight

Быстрый вход в игру и страницы для YouGile → **База знаний**.

## Что это за игра

**Эхо-Рыцарь (EchoKnight)** — top-down шутер-роглайт в Construct 3.  
Ты рыцарь на корабле-кузнице: выбираешь реликвию, ходишь по **6 планетам**, на каждой — цепочка **узлов-миссий** на большой локации (3840×2160). Между узлами возвращаешься на **хаб**: куёшь оружие, вешаешь моды, лечишься, летишь дальше. Финал планеты — **босс-голем**.

Жанр: roguelite · стелс · миссии · кузня / билд оружия.
