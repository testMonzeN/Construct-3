# Для разработчиков

## Сборка

```
node tools/build_echo.js
```

На выходе: `EchoKnight.c3p` в корне. В логе должно быть: `total=50`.

## Источник правды

| Файл | Зачем |
|------|--------|
| `tools/build_echo.js` | Логика, события, комнаты |
| `tools/art_echo.js` | Пиксель-арт |
| `EchoKnight.c3p` | Билд для Construct / сдачи |

Правки лучше в генераторе, не только в браузерном редакторе — иначе рассинхрон.

## Карта и индексы

- Клетка: `RoomIndex = RoomY * 3 + RoomX` (0…8)  
- `ClearedMap` — строка из 9 символов `"0"`/`"1"`  
- В Construct 3 `mid(...)` — индекс **с нуля** (не с единицы)

## Чеклист перед пушем / сдачей

1. `total=50` после сборки  
2. Зачистить **(1,1)** → на миникарте зелёная **только** она  
3. Углы карты: нет дверей «в никуда»  
4. **(2,0)** — босс → экран победы  
5. Кузница: 1–3 меняют стихию, 4–6 не сбрасывают  
6. WASD работает
