# Сдача ОПД

## Артефакты команды

| Что | Где лежит / куда сдать |
|-----|-------------------------|
| Игра | `EchoKnight.c3p` + GitHub |
| Риски (ДЗ2) | `ДЗ/02_ДЗ2_Риски.md`, `ДЗ/OPD_DZ_Tablitsy.xlsx`, `ДЗ/ДЗ2_Риски.docx` |
| Аналитика (ДЗ3) | листы в Excel / `ДЗ/ДЗ3_Аналитика.docx` |
| Концепт (ДЗ4) | `ДЗ/05_Эхо-Рыцарь_Концепт.md`, `ДЗ/ДЗ4_Концепт.docx` |
| Видео | 60–120 сек геймплея (ссылка рабочая!) |

Папка `ДЗ/` локальная (в git не пушится) — для сдачи формы кладите файлы на Диск и кидайте **ссылку**.

## Видео — что снять

Меню → выбор реликвии → 1–2 комнаты → кузница (1–3) → босс **(2,0)** → победа или R.

Перед сдачей: открыть ссылку в **режиме инкогнито**.
