# Как играть

## Управление

| Ввод | Действие |
|------|----------|
| **WASD** / стрелки | Движение |
| **ЛКМ** | Стрельба |
| **Пробел** | Рывок |
| **Q** | Реликвия |
| **1 / 2** | Слот оружия в руке |
| **G** | Обмен с оружием на полу |
| **Shift** | Стелс (медленнее, уже обзор врагов) |
| **T** | Тихий удар (в стелсе, рядом с незаагренным) |
| **E** | Кузница (в хабе) |
| **M** | Автомат модов (в хабе) |
| **V** | Звёздная карта планет (в хабе) |
| **F** | Карта узлов миссий (в хабе) |
| **P** | Пауза |
| **R** | В меню (после смерти/победы) |
| **X / Esc** | Закрыть окно UI |

## Поток забега

1. Меню → выбрать реликвию (heal / shield / nova)  
2. **Корабль-хаб** (~1200×640): кузнец, автомат модов, Эхо-врата  
3. **F** → карта узлов → клик по доступному → **большая локация** 3840×2160  
4. Выполнить цель миссии → возврат на корабль  
5. **V** — смена планеты (когда открыта)  
6. Последний узел планеты = **босс мира** → дальше следующая планета  

## Типы миссий

| Тип | Название | Цель |
|-----|----------|------|
| 0 | Истребление | Убить всех |
| 1 | Волны | Пройти `WaveMax` волн |
| 2 | Оборона | Отбить волны; **бур** в центре — если HP=0, провал |
| 3 | Узел-элита | Убить элиту |
| 4 | Босс мира | Убить голема (финал планеты) |
| 5 | Шпионаж | Взломать терминал до 100% (тревога замедляет) |
| 6 | Спасение | Подобрать заложника → эвак-зона |

## HUD и миникарта

- Слева: планета / тип / золото / оружие / моды / реликвия  
- Справа сверху: **цель миссии** + дистанция до POI  
- Справа снизу: **миникарта** — синий ты, жёлтый цель, красный враг  

## Кузница (хаб, E)

| Клавиша | Что | Цена |
|---------|-----|------|
| **1–3** | Стихия на эхо-клинок (огонь / лёд / молния) | 1 ядро |
| **4–6** | Сковать пушку (пепел / иней / гроза) | 2 ядра стихии |

Крафт пушки: новое → слот 1, старое 1 → 2, старое 2 → пол.

## Моды (хаб, M)

Инвентарь без лимита. На пушке в руке — **4 слота**, ёмкость **12** по весу.

| Мод | Вес | Эффект |
|-----|-----|--------|
| Остриё | 4 | +6 ур |
| Скорострел | 5 | быстрее стрельба |
| Вампир | 6 | +3 HP с убийства |
| Калибр | 7 | +10 ур |
| Искра | 3 | +4 ур |

## Стелс

- **Shift** — стелс: скорость ниже, радиус зрения врагов ~100 (обычно ~280)  
- Стены **блокируют обзор** (враг не видит сквозь стену)  
- Обнаружение → Alert + Alarm (на шпионаже взлом медленнее)  
- **T** в стелсе у незаагренного не-босса — тихий удар
