# Как играть

## Управление

| Ввод | Действие |
|------|----------|
| **WASD** (или стрелки) | Движение |
| **ЛКМ** | Стрельба |
| **Пробел** | Рывок |
| **Q** | Реликвия |
| **P** | Пауза |
| **R** | В меню (после смерти/победы) |

## Карта этажа 3×3

- Старт: **(1,1)** — центр  
- Кузница: **(2,1)**  
- Босс: **(2,0)**  

Миникарта справа: синий = ты, зелёный = зачищено, B/F = босс/кузница.

## Цикл забега

1. Выбрать реликвию в меню (heal / shield / nova)  
2. Зачистить комнату → открыть двери  
3. Ходить по этажу, собирать ядра и золото  
4. В кузнице усилиться  
5. Победить босса на **(2,0)** → «ЭТАЖ ПРОЙДЕН»

## Кузница

| Клавиша | Эффект |
|---------|--------|
| **1** | Стихия: огонь (тратит ядро F) |
| **2** | Стихия: лёд (ядро I) |
| **3** | Стихия: молния (ядро S) |
| **4** | +30 HP / 40 золота |
| **5** | +4 урона / 60 золота |
| **6** | +20 макс.HP / 80 золота |

**1–3** меняют стихию. **4–6** только покупки, стихию не сбрасывают.
