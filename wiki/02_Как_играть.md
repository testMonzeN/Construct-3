# Как играть

Краткая шпаргалка. Смысл игры — в **Об игре**.

## Управление

| Ввод | Действие |
|------|----------|
| **WASD** / стрелки | Движение |
| **ЛКМ** | Стрельба |
| **Пробел** | Рывок |
| **Q** | Реликвия |
| **1 / 2** | Оружие в руке (1 = эхо, 2 = пушка) |
| **G** | Обмен с оружием на полу |
| **Shift** | Стелс (медленнее; обзор врагов ~85 вместо ~200) |
| **T** | Тихий удар (в стелсе, рядом с незаагренным) |
| **E** | Кузница (хаб, подойти близко) |
| **M** | Автомат модов (хаб) |
| **V** | Карта планет (хаб) |
| **F** | Карта узлов (хаб) |
| **P** | Пауза (на паузе нет стрельбы / рывка) |
| **R** | В меню после смерти / победы |
| **X / Esc** | Закрыть окно UI |

## Типы миссий

| Тип | Название | Цель |
|-----|----------|------|
| 0 | Истребление | Убить всех |
| 1 | Волны | Пройти волны |
| 2 | Оборона | Защитить **бур**; HP бура = 0 → провал |
| 3 | Узел-элита | Убить элиту |
| 4 | Босс мира | Убить голема (финал планеты) |
| 5 | Шпионаж | Взлом терминала до 100% (тревога замедляет) |
| 6 | Спасение | Заложник → эвак-зона |

После узла — возврат на хаб. Хил: часть MaxHP за узел, больше — за смену планеты.

## HUD и миникарта

- Слева: планета, узел, золото, оружие, моды, реликвия, статус  
- Справа сверху: **цель** + дистанция до POI  
- Справа снизу: миникарта — синий ты, жёлтый цель, красный враг  

## Кузница (E)

Подойти к кузне на хабе. Слот **1** всегда эхо-клинок (не перезаписывается ковкой).

| Слот | Что | Цена |
|------|-----|------|
| **1–3** | Стихия на эхо (огонь / лёд / молния) | 1 ядро |
| **4** | Лечение | 45 золота |
| **5** | +урон (лимит 5) | 70+ золота |
| **6** | +MaxHP (лимит 4) | 90+ золота |
| **7–9** | Ковать пушку пепел / иней / гроза → **слот 2** | 2 ядра стихии |

Клавиши 1–6 или клик по кнопкам; ковка 7–9 — мышью. **X** — закрыть.

## Моды (M)

Инвентарь без лимита. На пушке в руке — **4 слота**, суммарный вес ≤ **12**.

| Мод | Вес | Эффект |
|-----|-----|--------|
| Остриё | 4 | +урон |
| Скорострел | 5 | быстрее стрельба |
| Вампир | 6 | хил с убийства |
| Калибр | 7 | +урон |
| Искра | 3 | +урон |

Дроп с врагов: ядро ~4%, мод ~3% (у волков выше).

## Стелс

- **Shift** — стелс; стены режут обзор врагов  
- Обнаружение → Alert (на шпионаже взлом медленнее)  
- **T** в стелсе у незаагренного не-босса — тихий удар (КД ~6 с)
