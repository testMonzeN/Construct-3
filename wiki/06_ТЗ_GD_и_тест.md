## Для тестера (Владислав)

### Цель

Полный прогон текущего билда, баг-лист без блокеров «не стартует / миссия не кончается / хаб мёртв».

### Обязательно

1. **Смоук** каждый день работы — [`05` → smoke](./05_Для_тестера.md#smoke).  
2. **Полный чеклист** — пункты в конце `05` (актуальный после правок 04.11).  
3. По одной миссии типов **0…6**.  
4. Босс планеты до фазы 2 и убийства; после 5-й — убедиться, что открывается **6-я (Бездна)**, победа только после её босса.  
5. Кузница + моды; слот 1 = эхо.  
6. Стелс + тихий удар (с дистанции ~90–120 или из-за стены).  
7. Пауза: нет боя и нет хаб-меню на ходу.  
8. Оборона: 2+ прогона — спавн не в одних и тех же точках.

### Сдать

Карточка «Тест прогон» + ✅/❌ по чеклисту; блокеры — сразу деву.

### Критерий «тест ок»

Старт → хаб → узел → победа → хаб → кузня/моды → ещё узел. Босс минимум одной планеты проходим; 6-я достижима после 5-й.

## Для геймдизайнеров (Timer, Дима)

### Цель

По ощущениям и багам теста подготовить **ECH-9** (числа / тексты / один дизайн-выбор по боссу), без смены архитектуры.

### Обязательно сделать

1. **Сыграть:** реликвия → 2–3 узла → кузница → оружие/моды; по возможности босс + тихий удар.  
2. Таблица **ECH-9** — только то, что реально меняете:

| Лист | Что писать |
|------|------------|
| `правки` | Было → стало → зачем |
| `миссии` | Волны / бур / шпионаж / спасение |
| `враги` | Мясо / вата на слое N; пул обороны |
| `босс` | HP, фаза 2, адды + **см. блок ниже** |
| `кузница` | Цены / лимиты |
| `реликвии` | КД / сила |
| `тексты` | Имена, подсказки, победа/поражение |
| `хотим позже` | Идеи не в этот спринт |

3. **Темп:** ~**6–12 мин** до босса 1-й планеты для знакомого игрока.  
4. **Не ломать:** типы 0…6, F/V/E/M, размеры локаций, слот 1 = эхо.

### Решение по боссу (обязательно в ECH-9 или явный «позже»)

Тест: босс сейчас в основном танк + призыв нетопырей; мало читаемых дальних угроз.

**Нужно выбрать один паттерн** (или официально отложить в `хотим позже`):

| Вариант | Суть | На что ответить в таблице |
|---------|------|---------------------------|
| A | «Содрогание земли» — зона/волна по полу с телеграфом | Радиус, КД, урон, фаза 1/2/обе |
| B | Огромный снаряд в героя — уворот **рывок** | Скорость снаряда, телеграф, урон, КД |
| C | Кольцо пуль вокруг босса → разлёт наружу | Число пуль, КД, урон, фаза |

В карточке/листе `босс` коротко: **выбранный вариант + числа + в какую фазу**. Без этого дев не пилит дальнюю атаку в ECH-9.

### Сдать

- Sheet **ECH-9** + ссылка в YouGile «ECH-9 баланс».  
- 5–10 строк: что болит сильнее (сложность / скука / тексты / босс).  
- Список «не трогаем в ECH-9».  
- Явный вердикт по дальнему бою босса: **A / B / C / позже**.

### Критерий «GD ок»

Конкретные числа/тексты + решение по боссу; дев переносит без «а что вы имели в виду».
